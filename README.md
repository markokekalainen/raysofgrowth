# Rays of Growth — Website

## Commit Messages

Use [Conventional Commits](https://www.conventionalcommits.org/): `<type>(<scope>): <description>`.

Types used in this repo's history:

- `content` — new or changed page/blog content
- `feat` — new functionality or tooling (e.g. scripts, editor commands)
- `fix` — bug fixes
- `chore` — maintenance (deploy triggers, config, cleanup)
- `styles` — CSS/visual-only changes
- `image` — asset/image changes

Scope is the affected area (e.g. `blog`, `lenkki`, `skills`, `navigation`) — omit it only when the change is repo-wide.

Examples from history:

```
content(blog): add täydellisyyden tavoittelu post
feat(skills): add blog-draft and blog-publish slash commands
fix(lenkki): poisskeusaika 3.5.
chore: trigger deployment
```
